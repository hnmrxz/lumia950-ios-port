## Statements that are now wrong or need a pointer

The last two days produced three corrections, and the older notes were not edited in place. Each of these
should be read with the correction beside it:

1. **"Replacing `EFI/boot/bootarm.efi` installs the chain"** — wrong. The firmware boots
   `EFI/boot/bootarm.efi`, and the unlocked boot manager is what looks for `UEFI.elf`; replacing the
   loader is what broke mass storage, not what installs the chain
   (superseded notes folded into `docs/hardware/handset-boot-chain.md`).
2. **"BootShim is the missing piece"** — half right. A shim is part of the documented chain, but the
   shim fetched from `imbushuo/boot-shim` is **ARM32** (`PE machine 0x01C4`) and cannot run on this
   AArch64 handset; the AArch64 shim ships inside the Lumia950XLPkg package (42,976 B,
   `8AF09F13-…`). See `docs/hardware/2026-11-24-wpinternals-integration.md` and this audit.
3. **"Pointing `{default}` at BootShim is how the chain starts"** — wrong for this store. The Windows
   Phone BCD has no display order, and hijacking `{default}` makes the manager fall back to its boot
   sequence and the Windows reset flow (the two gears). The correct target is the sequence start entry
   (`{01de5a27-…}`, `mobilestartup.efi`) or a menu selection reached by holding Volume Down.
